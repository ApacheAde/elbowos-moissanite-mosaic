# Moissanite Mosaic

Full-colour Python 3 neon falling-block arcade for [ElbowOS](https://x.com/ElbowOS).

Drop 2×2 moissanite tiles into a six-wide well. Cycle the square, slide it, and clear matching 2×2 clusters. Combos shatter the lattice.

## Play

```bash
python3 -m pip install -r requirements.txt
python3 moissanite_mosaic.py --play
```

Controls: **A / D** slide · **W / Space** cycle the 2×2 · **S** soft drop · **R** reset · **Esc** quit.

## Record a 9:16 reel

```bash
python3 moissanite_mosaic.py --record
```

Writes `/home/workdir/artifacts/MOISSANITE_MOSAIC_ElbowOS.mp4` (1080×1920, 15s, 30fps, H.264).
